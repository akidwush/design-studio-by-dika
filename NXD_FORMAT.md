# NXD schema 1

`.nxd` is a ZIP container, not a renamed bitmap. UTF-8 `document.json` contains `schemaVersion: 1`, `width: 768`, `height: 768`, `selected` (zero-based layer index), and ordered `layers` (bottom to top). Each layer has UUID `id`, `name`, `kind` (`raster`, `image`, `vector`, `svg`), `visible`, `locked`, `opacity` (0–1), `x`, `y`, `scale`, `rotation`, `shape`, `color`, `strokeColor`, `strokeWidth`, and `resource`.

Each raster/image resource is `raster/<uuid>.png`, exactly 768×768 ARGB. Native vector shapes and preserved imported SVG occupy `vector/<uuid>.svg`. Native shapes are also represented by their editable parameters in JSON; their generated SVG must agree with those parameters. Imported SVG XML is retained verbatim in its resource. `preview.png` is the composite transparency-preserving preview. IDs and array order survive round-trip. Undo history and viewport zoom are session state, not part of schema 1. Group layers and arbitrary document sizes are not supported yet. Unknown schema versions are rejected rather than silently migrated.

Coordinates are document pixels. The same center-based affine transform is applied to every layer: center at (384,384), scale, rotate, restore center then translate x/y. Drawing maps touch input through inverse viewport and inverse layer matrices, keeping raster/vector coordinates consistent.

Limits: 8 layers; 32 MiB compressed file; 20 entries; 8 MiB per decompressed entry; 48 MiB total decompressed bytes; 100-character names; decoded images ≤8192 per side and ≤32 million pixels. Image import downsamples then fits to the fixed document. ZIP paths must match the exact schema allowlist; duplicate/unknown/path traversal entries, missing resources, nonfinite/out-of-range transforms and duplicate IDs are rejected. No archive entry is extracted to disk.

SVG: ≤1 MiB UTF-8, ≤5000 elements, ≤16 levels, ≤100000 characters per attribute. Explicit supported elements: svg/g/path/rect/circle/ellipse/line/polyline/polygon/defs/linearGradient/radialGradient/stop/clipPath. Attribute allowlist is in SvgGuard. Basic geometry, transforms, paint, evenodd, gradients and clipping are preserved. CSS/style, text, images, use/href, filters, masks, scripts, foreign objects, DTD/entities and external resources are rejected. No network permission is declared. Rendering fidelity is fixture-tested only, not claimed for arbitrary SVG.

Internal recovery and last-save staging use Android AtomicFile (backup/commit). SAF writes copy prepared bytes to the selected Content URI off the UI thread. A document provider may not support transactional replacement; an interrupted external write can be partial. The internal `last-save.nxd` and autosave remain independent recovery copies. Use Save As for valuable files; a failed write reports failure. Home → Pulihkan autosave restores the latest successful autosave, including supported layer structure.
